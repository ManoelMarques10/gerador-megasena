
# 🎲 Gerador Mega-Sena

🎰 Simulador básico de jogos para a Mega-Sena.

## 📌 Sobre

Este projeto é um simulador simples que gera jogos aleatórios para a Mega-Sena. O usuário informa quantos jogos deseja gerar e o programa cria combinações únicas de 6 números entre 1 e 60 para cada jogo.

## ⚙️ Funcionalidades

- 🎯 Geração de múltiplos jogos com números únicos e ordenados.
- ✅ Validação da entrada (só aceita números inteiros maiores que zero).
- 🎨 Uso de cores no terminal para deixar o visual mais agradável.
- ⏳ Pausa entre os sorteios para simular o processo de geração.

## ▶️ Como executar

1. 📥 Clone o repositório ou copie o código.
2. 🐍 Execute o script com Python no terminal:

```bash
python gerador_megasena.py
```

3. 🧠 Digite quantos jogos deseja e deixe o resto com o programa!

## 🛠️ Tecnologias utilizadas

- Python 🐍
- Bibliotecas padrão: `random`, `time`
